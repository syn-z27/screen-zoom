# ScreenZoom

macOS のアクセシビリティにある「修飾キー＋スクロールで画面全体をズーム」を Windows で再現する常駐ツール。

**Win＋ホイール**で操作する。

## 機能

- **Win＋ホイール上下**で画面全体を拡大 / 縮小（1 ノッチ約 1.12 倍、最大 20 倍、等倍付近で 1.0 にスナップ）
- ノートPCの**タッチパッドの二本指スクロール**にも対応（指を上に動かすと拡大）
  - マウスとタッチパッドは Raw Input で見分ける。タッチパッドは判定待ちのため 40〜50ms ほど遅れてズームする
- 拡大中は**マウスカーソルに追従**して表示領域が移動（macOS の「ポインタに合わせて連続的に移動」相当）
- Windows 標準の Magnification API を使用するため、拡大中もクリック位置はずれない
- Win＋ホイール操作後に Win キーを離してもスタートメニューは開かない
- タスクトレイ常駐（右クリックメニュー）
  - 有効 / 無効の切り替え（アイコンのダブルクリックでも可）
  - ズームをリセット
  - Windows 起動時に実行（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` に登録）
  - 終了（終了時・ログオフ時は等倍に戻す）

## 動作環境

- Windows 10 (1703 以降) / Windows 11、64 ビット
- .NET Framework 4.x（Windows に標準搭載）

## ビルド

追加インストール不要。.NET Framework 付属の C# コンパイラ `csc.exe` を直接呼び出す。

```bat
build.bat
```

同じフォルダに `ScreenZoom.exe` が生成される。起動中の場合は exe を上書きできないため、トレイから終了してからビルドする。

## 使い方

`ScreenZoom.exe` を起動するとタスクトレイに虫眼鏡アイコンが表示される。Win キーを押しながらマウスホイールを回す（タッチパッドなら二本指で上下に動かす）。

## 制限事項

- Win キーを押している間は画面全体を透明なウィンドウで覆うため、その間のクリックはアプリに届かない
- 管理者権限で動作しているウィンドウが前面にあると反応しない場合がある（必要なら ScreenZoom も管理者として起動）
- マルチモニター環境での動作は未確認
